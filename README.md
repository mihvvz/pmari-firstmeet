# primeiro-encontro.exe 💜

Mini site responsivo para surpreender sua namorada antes do primeiro encontro presencial.

## Como abrir
1. Extraia a pasta `primeiro-encontro`.
2. Abra `index.html` no navegador.
3. Para publicar e mandar um link, envie os três arquivos (`index.html`, `style.css`, `script.js`) para um repositório GitHub e ative o GitHub Pages, ou publique a pasta em um serviço de hospedagem estática.

## Personalização rápida
Abra `script.js` e altere o objeto `PERSONALIZACAO` no começo do arquivo:
- `apelido`: como você chama sua namorada.
- `data`: data ou frase do encontro.
- `mensagemFinal`: sua mensagem pessoal. Preserve as crases que envolvem o texto.

O restante do texto e das estatísticas pode ser editado diretamente no `index.html`.
Não coloque informações privadas ou sensíveis na página se o link for público.

## Observações
- O site usa HTML, CSS e JavaScript puro.
- A fonte é carregada do Google Fonts; se estiver sem internet, haverá fonte alternativa.
- As estatísticas são brincadeiras fictícias.
